## Non-Functional Requirements

| ID | Requirement | Category | Target |
|----|-------------|----------|--------|
| NFR-P4-OPS-A | Never-kill upstream: no CLI code path may signal a PID it did not spawn and record; forbidden: kill-by-port scan, `fuser`, `helix prune`, `helix delete`, `docker rm\|kill\|volume rm`, `--persist`; foreign holders reported with "NEVER kill", never displaced. Runbook equivalents: REQ-OPS-RUN-04, REQ-OPS-RUN-13, REQ-OPS-RUN-14 | Safety | Foreign PIDs unchanged (same PID before/after) across `start\|stop\|status\|doctor`; static grep for forbidden primitives empty; `doctor` on held port exits 3 report-only |
| NFR-P4-OPS-B | Secret non-printing: no subcommand prints `AGENT_MEMORY_SECRET` (or any env value); output is `bearer: armed\|unset` / `secret: present\|missing` flags only; state file never contains it. Runbook equivalents: REQ-OPS-RUN-01 (C4), REQ-OPS-RUN-02 (exit 5), REQ-OPS-RUN-03 | Security | Synthetic secret appears 0 times in stdout+stderr of all four subcommands and in the state file (AC-P4-OPS-B, AC-OPS-RUN-03) |
| NFR-P4-OPS-C | Port-parity defaults untouched: bare `npm run dev` still listens on `3111`, `HELIX_URL` default stays `http://localhost:6969`, hooks/plugin clients stay on `http://127.0.0.1:3111`; slots are derivation, not a default change. Runbook equivalent: REQ-OPS-RUN-11 (port/instance discipline) | Compatibility | `git diff` shows defaults unchanged; `verify-env` PASS; slot-1 `status` reports `3111/6969` (AC-P4-OPS-C) |
| NFR-P4-OPS-D | Durability across restart: data under an explicit data dir survives `helix restart <instance>` AND a full CLI `stop`/`start` cycle; migration retains the old MinIO volume for rollback. Runbook equivalents: REQ-OPS-RUN-07, REQ-OPS-RUN-08 | Reliability | save → restart/stop+start → `search` returns the row; `docker volume ls` unchanged (AC-P4-OPS-D, AC-OPS-RUN-06) |
| NFR-P4-OPS-E | Zero new dependencies + suites green: dependency manifests and lockfile unchanged; `typecheck` clean; `verify`, `verify-env`, `verify-lifecycle`, `verify-capture`, `verify-skills`, `verify-injection`, pinned gitleaks all PASS; port guard respected. Runbook equivalents: REQ-OPS-RUN-09, REQ-OPS-RUN-12 | Compliance | `git diff package.json package-lock.json` limited to `bin` + `verify-ops`; suite counts at bar (243/21/123/137/73); CI workflow diff empty (AC-P4-OPS-E, AC-OPS-RUN-08/09) |
| NFR-P4-OPS-F | Ley 172-13 output hygiene: `doctor`/`status`/`--migrate` output contains no memory content, no prompt text, no raw PII, no secrets — only ports, booleans, counts, HTTP codes, and allowlisted paths (`$HOME` collapsed to `~`). Runbook equivalents: REQ-OPS-RUN-03 (field allowlist), REQ-OPS-RUN-10 (evidence paste hygiene) | Privacy (Ley 172-13) | Canary memory string appears 0 times in all four command outputs and the migration report (AC-P4-OPS-F, AC-OPS-RUN-03); R2 co-signs the §4b allowlist before implementation |
