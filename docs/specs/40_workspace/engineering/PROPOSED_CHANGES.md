## Summary

One new Node ≥20 ESM binary, `bin/agent-memory.mjs`, adds `start|stop|status|doctor` over the existing dev instance and over derived multi-instance slots, with per-slot port quartet derived by pure math (`R(N) = 3111 + 3(N−1)`, `H(N) = 6969 + (N−1)`) and projected through env/flags only, plus an explicit data dir (`AGENT_MEMORY_DATA_DIR` → `HELIX_DATA_DIR`) with fail-closed MinIO migration. ## Rationale

The spec asks for an ops surface without touching frozen source, and that is exactly what this row set delivers: all per-slot variability (REST port, Helix port, URLs, data dir) is derived at the CLI edge and projected through env/flags (`AGENT_MEMORY_PORT`, `helix start|add --port`, `HELIX_URL`, `AGENT_MEMORY_URL`) — zero `src/**`/`db/**` edits, so `git diff --stat src/ db/` stays empty (**REQ-P4-OPS-06**, `SPEC-P4-OPS.md:76-81`, invariant INV-010 `ARCHITECTURE.md:148-150`). The default `3111`/`6969` parity the contract depends on is untouched because slots are derivation, not a default change (**NFR-P4-OPS-C**, `SPEC-P4-OPS.md:107-110`).

The reconciled **doctor exit contract** is taken verbatim from the R8 runbook, which both specs declare canonical: exits **0 = healthy · 1 = doctor-check-failed · 2 = usage · 3 = upstream-holds-port · 4 = helix-down · 5 = secret-missing**, one terminal `VERDICT: <name>` line, all C1–C5 checks printed before the verdict, fixed precedence **5 > 4 > 3 > 1 > 0** (`SPEC-P4-OPS-RUNBOOK.md:262-275` = §4a canonical; consumed by `SPEC-P4-OPS.md:71-75,195-198`; mirrored `ARCHITECTURE.md:86-102` INV-006). `status` keeps its own separate 0/1/2 contract and is **not** `doctor` (INV-009, `ARCHITECTURE.md:146-147`). `upstream-holds-port` (3) reports and exits without ever signaling the foreign holder (`REQ-OPS-RUN-04`, `SPEC-P4-OPS-RUNBOOK.md:95-97`).

The **accepted quartet math** is `R(N) = 3111 + 3(N−1)` (REST) and `H(N) = 6969 + (N−1)` (Helix), with reserved `R+1`/`R+2` reserving address space only — never bound, never signaled (`SPEC-P4-OPS.md:200-219`). Slot 1 reproduces brief §3.2's enumeration literally (`3111` REST + `6969` Helix + 2 reservados); N≥2 ⇒ quartet ∩ `{3111,3112,3113,6969}` = ∅; the derivation never yields `3151`, the documented reroute example. This reading is assumption **A1**, accepted by the orchestrator 2026-09-24 (`SPEC-P4-OPS.md:275-278`).

Data-dir precedence (`--data-dir` > `AGENT_MEMORY_DATA_DIR` > `~/.local/share/agent-memory/<slot>/`), the state file outside `HELIX_DATA_DIR`, and the fail-closed migration (dry-run default → verified backup → copy → verify; MinIO volume never destroyed) close **REQ-P4-OPS-07/08** and the brief's "falsifiable bet" (`BRIEF-p4-ops-control-plane.md:71-74`, `SPEC-P4-OPS.md:82-94`). Doc closure (README + TEST_MATRIX) closes **REQ-P4-OPS-09** together with **REQ-OPS-RUN-10/15**. Full REQ → change → evidence mapping is the spec's own traceability table (`SPEC-P4-OPS.md:314-332`, `SPEC-P4-OPS-RUNBOOK.md:351-369`), which names this file as the proposed-change artifact for every row.
