## Item (g) — process-kill surface trace (primary item)

Exact signal targets, line by line:

1. `kids: Spawned[] = []` (`:172`) — pushed to **only** inside `spawnCapture()` (`:216`), whose `child` comes from this process's own `spawn(command, args, …)` (`:179-183`). Two entries ever: the section-A/C server (`spawn("npx", ["tsx","src/server.ts"])`, `:222`) and the section-B hook (`spawn(process.execPath, ["hooks/capture.mjs", …])`, `:359`).
2. Every `.kill()` in the file is `kid.child.kill(...)` or `server.child.kill(...)` / `hook` via the same objects — i.e. **PID-targeted at children this process spawned**. Signals used: SIGTERM then SIGKILL escalation, guarded by `exitCode() === undefined` (`:350-352`, `:444-453`) so a reaped PID is never re-signaled (PID-reuse window closed by the still-live-child guard).
3. **No pattern matching exists.** Repo-wide grep `pkill|pgrep|killall|process\.kill|execSync(kill` across `*.{ts,mjs,js,sh,md}` → **0 matches**. There is no code path that enumerates, matches, or signals *any* process it did not spawn. The string `tsx src/server.ts` is never used to find anything — it is only ever argv of its own spawn.
4. **Can it hit the live evidence server on 3151?** No. Its spawned servers are configured via `legacyOnlyEnv({AGENTMEMORY_PORT: "3199", …})` (`:224-228`) — every child binds **3199 only**; 3151 is unreachable by construction, and no signal targets a PID outside `kids`.
5. **Can it hit 3111/3112/3113 (upstream)?** No — never enumerated, never signaled; the preflight on an occupied **3199** (`:274-280`) **FAILs and returns `false` without killing anything**, with the remedy text explicitly naming "never touch 3111/3112/3113/3151".
6. Cleanup runs in `finally` (`:467-469`) so exception paths still reap *only its own* children; the blocker listener is closed, not signaled (`:454-457`).

**Conclusion:** the never-kill-adjacent guarantee is structurally enforced (spawn-origin tracking + zero matching + fail-closed preflight), not merely by convention. The only residual is RK-010 (orphaned *own* child on Ctrl-C — a leak, never a stray kill). This reviewer issued **no signals and did not run the script** (forbidden: port conflict with parallel reviewers); the trace is from a full read of all 482 lines.
