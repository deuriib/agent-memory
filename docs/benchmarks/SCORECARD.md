Notes:

- The harness identity-guards first (POST /memory/recap must 200) and refuses to
  write anywhere that is not our server; it exits 1 with the runbook when the health
  gate fails. All calls use the dedicated project `agent-memory-eval`.
- `EVAL_MODE` defaults to `rest`; a new mode only needs another `EvalClient`
  implementation in `scripts/eval.ts`.
- `AGENT_MEMORY_SECRET` is forwarded as a bearer header when set (never logged).
- Determinism (RL-004): the metrics are pure — same corpus + same ranked ids ->
  identical numbers. Search ORDERING can differ in a warm process because the
  in-process recall ledger (never persisted) tilts fused ties; the ranks in this
  appendix are what THIS run observed.
- If searches report `index_not_found`, run `npx tsx scripts/bootstrap.ts` first
  (idempotent), then re-run.
